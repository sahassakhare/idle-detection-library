🚀 Angular Idle Detection Demo

A comprehensive demonstration of the Angular Idle Detection Library with custom templates and actions.

✅ Demo Components Ready

All example components have been built and are ready for testing.

🌐 Access the Live Demo:
The Angular application should be running on one of these ports:
  • http://localhost:4200
  • http://localhost:4201
  • http://localhost:4202

📋 Demo Features Available

🔧 Basic Demo

Standard idle warning dialog with multi-tab coordination (2 min idle, 20 sec warning)

🎨 Custom Template

Animated modal with circular progress indicator and custom styling

📄 Template Reference

Minimal dark theme using Angular template references

⚡ Custom Actions

4 custom action buttons with interactive configuration controls

🧪 How to Test

  1. Visit the demo URL above - you should see 4 tabs at the top
  2. Navigate between tabs to see different implementations
  3. Wait for idle timeout (2 minutes) or reduce for testing
  4. Test multi-tab coordination by opening multiple browser tabs
  5. Try custom actions - notice different behaviors
  6. Check browser console for debugging information
  7. Inspect localStorage for 'idle-expiry-demo-idle-channel' key

⚠️ If Demo Not Loading

The Angular development server might need to be restarted. Try:

  1. Check if any of the port URLs above are accessible
  2. Look for any TypeScript compilation errors in the terminal
  3. Restart the Angular server: npm start
  4. Try different ports if needed

📁 Project Structure

The demo includes these example components:

  • app.component.ts - Main app with tab navigation
  • custom-template-example.component.ts - Animated custom template
  • template-ref-example.component.ts - Template reference approach
  • custom-actions-example.component.ts - Custom action buttons
